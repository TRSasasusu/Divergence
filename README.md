# Divergence

"We take risks, and make peace with the consequences."

Divergence is short story mod for Outer Wilds originally created entirely using New Horizons for the January 2023 New Horizons Jam. Discover a hidden secret nested within the Hearthian system, and find an untold story of what might have been.

## Prerequisites

Requires New Horizons and the Echoes of the Eye DLC for Outer Wilds.
